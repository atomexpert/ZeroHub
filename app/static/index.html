Памятка ZeroHub

🧠 Паспорт проекта

Нажмите «✨ Собрать автоматически» в окне «🧠 Память» один раз (работает и на старых, и на новых проектах): все вкладки сразу знают стек, карту файлов и запреты, экономя 30–50k токенов на поиске файлов.

🧭 Штаб (План) ➔ 🚀 В Код

Черновые идеи и архитектуру обсуждайте во вкладке План (они не засоряют общую память), а готовое ТЗ отправляйте одной кнопкой «🚀 В Код» — она сразу включает в целевой вкладке режим «Терминал», чтобы агент за один проход внёс правки и прогнал проверки без повторной отправки команд.

📡 Живой Пульс и Светофор файлов

Вкладки сами видят последние реальные правки в проекте и получают предупреждение Светофора файлов, если соседняя вкладка прямо сейчас редактирует тот же файл.

@чат и закладки 🔖

Введите @ в поле ввода проекта (или нажмите кнопку @ у скрепки), чтобы точечно подтянуть сжатые выводы и отмеченные закладки 🔖 из любого соседнего чата этого проекта.

☰ Содержание чата и закладки 🔖

🖱️ Быстрые клики и навигация

Клик колёсиком мыши закрывает вкладку сверху (Alt + W) или убирает строку из «⚡ Недавние». Клик по цветному шильдику проекта сразу раскрывает его папку слева.

🧹 Когда выгодно сжимать контекст

Оптимальный порог кнопки «Сжать контекст»: 160k–190k токенов для моделей Gemini (80–95%) и 130k–150k для Claude (65–75%) — до падения точности и скачка расхода квоты.

Управление пользователями и общими проектами

Защита входа и песочница активны: пароли хранятся в виде криптохэша PBKDF2-SHA256 (210 000 итераций), каждый гость заперт в своей папке data/workspaces/<логин> без доступа к терминалу вашего ПК и вашим чатам.
Новый пользователь
⚠️ Даёт доверенному пользователю прямой доступ к системе Windows и GPU ПК в личных и host-проектах (в docker-проектах сохраняется контейнер; для запуска модели на GPU в команде указывайте $env:CUDA_VISIBLE_DEVICES="0").
Работает через встроенный MCP-шлюз hub_sandbox на 127.0.0.1: Linux-бинарник agy не требуется, OAuth-токены и Windows-терминал хоста никогда не попадают в контейнер.
Контур общих проектов: проверка статуса Docker…
При создании общего проекта по умолчанию выбирается 🐳 Docker (MCP-песочница hub_sandbox без Linux-бинарника agy и без проброса OAuth-секретов хоста). Готовый образ с Node.js 22, Rust/Cargo и Python лежит в Dockerfile.sandbox (сборка: docker build -f Dockerfile.sandbox -t agy-hub-sandbox:latest .).
