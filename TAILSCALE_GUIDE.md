# 📱 Подключение смартфона к Antigravity Hub за 2 минуты

Antigravity Hub работает сразу в двух режимах подключения со смартфона:

---

## Вариант 1. Дома по общему Wi-Fi (0 настроек — работает сразу)
Если компьютер и смартфон подключены к одному домашнему роутеру:
1. Запустите **Antigravity Hub** на ПК (`start_hub.bat` или фоновый `start_hub_silent.vbs`).
2. В левом нижнем углу интерфейса нажмите **«📱 Телефон / QR»**.
3. Наведите камеру телефона на QR-код (адрес вида `http://192.168.x.x:8765`), введите ваш ПИН-код (по умолчанию `1234` — сразу смените его в `⚙️ Настройки`).
4. Установите иконку на главный экран телефона:
   - **Android (Chrome):** меню `⋮` → **«Установить приложение»** (*Install app*).
   - **iPhone (Safari):** кнопка **«Поделиться»** → **«На экран „Домой“»**.

---

## Вариант 2. Из любой точки мира по 4G / 5G / чужому Wi-Fi (через Tailscale)
**Tailscale** создаёт зашифрованный прямой P2P-туннель только между вашими собственными устройствами (без открытия портов на роутере и без «белого» IP).

### Шаг 1. Установка на ПК (1 минута)
1. Скачайте Tailscale для Windows с официального сайта: https://tailscale.com/download
2. Установите и войдите под любым удобным аккаунтом (можно отдельный Google / GitHub / Microsoft — он никак не связан с аккаунтами внутри Antigravity!).
3. **Важно для дружной работы с вашим прокси (`127.0.0.1:10808`):**
   - В значке Tailscale в трее убедитесь, что **Exit Node = None** (по умолчанию так и есть).
   - Не включайте TUN-перехват `100.64.0.0/10` в стороннем VPN/прокси-клиенте (обычный системный прокси `127.0.0.1:10808` вообще не мешает Tailscale и работает с ним идеально параллельно!).

### Шаг 2. Установка на смартфон (1 минута)
1. Установите официальное приложение **Tailscale** из Google Play или App Store.
2. Войдите **в тот же аккаунт Tailscale**, что и на ПК, и включите тумблер `Connected`.

### Шаг 3. Сканирование QR-кода
1. Нажмите **«📱 Телефон / QR»** в Antigravity Hub на ПК — приложение автоматически обнаружит ваш Tailscale-адрес (`http://100.x.y.z:8765`) и сгенерирует для него QR-код.
2. Отсканируйте QR-код телефоном и добавьте приложение на главный экран — теперь ваш домашний Antigravity Hub мгновенно открывается по мобильному интернету откуда угодно!

---

## Полезно знать: Автозапуск без чёрного окна консоли
- Файл **`start_hub_silent.vbs`** запускает сервер тихо в фоне через `pythonw.exe` без окна терминала (логи пишутся в `data\hub_server.log`).
- Если хотите, чтобы Hub стартовал сам при включении Windows: нажмите `Win + R` → введите `shell:startup` → перетащите туда **ярлык** на файл `start_hub_silent.vbs`.
- Для ручной остановки фонового сервера используйте **`stop_hub.bat`**.
