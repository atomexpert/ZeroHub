# ZeroHub v1.0.0

ZeroHub — портативное многопользовательское рабочее пространство для управления проектами и ИИ-агентами. Сервер запускается на Windows и Linux VPS. Клиенты работают в браузере или как мобильное PWA.

## Рабочие режимы

- Чаты с поддержкой нескольких провайдеров, истории и передачи контекста между вкладками.
- Проектные вкладки для запуска Google Antigravity CLI, OpenAI Codex и Claude Code. OpenRouter поддерживает выбор моделей и параллельный консилиум.
- Голосовой ввод на CPU и синтез речи, общие проекты и персональные рабочие пространства.

## Архитектура

- FastAPI, Uvicorn, WebSocket и SQLite. Фронтенд использует Vanilla JS, CSS и Service Worker.
- Данные сервера хранятся в `./data`, персональные проекты — в `./users`, общие — в `./shared_projects`.
- Доступ разграничивается ролями и уровнями `read_only`, `docker_full`, `host_full`. Для общих проектов доступна Docker-песочница.
- HTTP и HTTPS используют порты 8765 и 8766 по умолчанию. Для доступа с других устройств поддерживаются локальная сеть, Tailscale и обратный прокси.

## Выпуск и сопровождение

Публичный репозиторий `atomexpert/ZeroHub` получает проверенный снимок исходников. У мастер-стенда остаётся собственная история разработки. Версия приложения хранится в `VERSION`, локальные секреты — в игнорируемом `.env`. Публичные проверки обновлений работают без токена.

Перед коммитом запустите `tools/verify_hub.py` интерпретатором из `.venv`. Тесты используют временные каталоги и изолированную SQLite. Установка, запуск и подключение клиентов описаны в README.md.
